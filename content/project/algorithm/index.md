# Leetcode hot100

## 技巧题

### 只出现一次的数字

使用异或操作遍历数组，重复出现的数字会变成0，单独出现的数字会保留✅

### 多数元素

使用一个变量记录当前遍历过的数字 ，如果数字相同加一，否则减一，减为零时则更新为下一个出现的数字，这样多数的数字会被保留✅

### 颜色分类

三种解决方法：

#### 单指针

逐个排序，先排序0，返回排序后的索引，然后排序1，排序完就为答案，这里可以利用go切片的特性（共享底层数组）

#### 双指针

1.一个指针p2记录2可以放的位置（初始位置为数组最后一个索引），一个指针p1记录0可以放的位置（初始位置为0），然后遍历数组，如果等于2往末尾放，然后减一，如果为0放前面，指针加一，遍历的结束条件为索引等于p2指针的位置

2.p0记录0要存放的位置，p1记录1要存放的位置，遍历数组，如果等于0，与p0位置进行交换，然后判断交换完的位置是否为1，为1再和p1交换，然后更新p0、p1加一，如果等于1，则和p1交换，p1++

### 下一个排列

可以理解为找到下一个字典序增加的排列，要求增加的幅度为最小，那就可以理解为：从数组最后找到一个数，满足其右边元素为降序排序，然后在这个降序排列中找到一个数，比当前这个数字大，但是是大的最少的，两者进行交换，然后对右边的数字进行升序排序。

### 寻找重复数

三种解法：

#### 二进制

判断二进制位数相对于数字不重复时增加的二进制位，逐步累加到答案中

#### 龟兔赛跑算法

某个数重复了两次以上，如果规划i到nums[i]为一条边，那肯定存在一个环，这时需要找到环的入口就可以找到重复的数

#### 二分查找

cnt[i]表示小于等于i的数字的数量，重复之前的数字满足cnt[i]<=i，重复之后的数字满足cnt[i]>i，根据这个条件进行二分查找，cnt[i]>i的第一个位置就是重复的数字，此时i就是答案。

## 动态规划

### 不同路径

机器人从网格的左上角走到右下角，基础的二维动态规划，当前位置的等于上方位置和左边位置加一，初始位置为一，边界位置（第一行、第一列）等于前面的位置加一，dp[m-1] [n-1]就为答案✅

### 最小路径和

与第一题思路一样，需要把当前位置的值加上而不是加一。✅

### 最长回文子串

对于字符串的单个字母肯定都是回文串，初始时把dp状态数组全部置为true，遍历寻找L=2->n,当前串为回文串的前提是去掉两头的两个字母后子串是回文串，两头字母相同，如果是更新答案✅

### 最长公共子序列

```go
dp[i][j] = max(max(dp[i-1][j], dp[i][j-1]), dp[i-1][j-1]+1) //s1[i]==s2[j]
dp[i][j] = max(max(dp[i-1][j], dp[i][j-1]), dp[i-1][j-1]) //s1[i]!=s2[j]
```

### 编辑距离

```go
//可用操作：增加、删除、修改
//处理边界情况一个子串为0，另一个子串的操作就是当前的长度
dp[i][j]  = min(min(dp[i-1][j]+1, dp[i][j-1]+1), dp[i-1][j-1]+1) //s1[i]!=s2[j]
dp[i][j]  = min(min(dp[i-1][j]+1, dp[i][j-1]+1), dp[i-1][j-1]) //s1[i]==s2[j]
```

## 贪心算法

### 买卖股票的最佳时机

维持一个当前股票最低价，往后遍历，如果比当前值大就计算差值更新答案，如果比最低价小就更新最低价✅

### 跳跃游戏

维护一个当前能跳到的最大值，从当前位置遍历到最大值，这中间根据能跳越到的位置更新最大值，若最后最大值小于数组长度，则不能，否则能✅

### 跳跃游戏2

可以理解为区间更新，维护每一步可以跳跃的最大值，然后遍历当前区间，在这个过程中计算一个最大跳跃值是下一个步遍历的范围，然后更新步数，最终返回答案✅

### 划分字母区间

先统计每个字符出现的最后的索引位置，然后遍历字符串，维护一个左侧的下标和当前区间内最大的索引位置，如果遍历到的位置索引等于最大索引，计算当前分组，更新左侧值，计算下一区间✅

### 搜索旋转排序数组

这里比二分查找要考虑更多的条件，选择“标兵”，根据标兵来判断target值所处的位置位于左半区还是右半区，然后再判断mid值与target的大小关系来移动l,r的位置

### 寻找旋转排序数组中的最小值

### 寻找两个正序数组的中位数

二分，不过进行二分的是中位数的位置，

首先判读两个数组的长度和是奇数还是偶数，如果是奇数则只需求一个第k小的值就好，偶数就要求两个，

求第k小的值，初始时两个数组的索引都为0，然后将k二分，比较两个数组的索引index+k/2的值的大小（注意不要超过数组的长度），小的部分说明这部分是肯定在前k小的序列中，从k值中去除这部分，然后处理去除后的k1，边界条件就是1.其中一个数组被遍历完，返回另一个数组的第index+kn的值，2.kn==1，返回两个数组中的较小值

## 回溯

### 全排列

```go
dfs 0 -> n - 1
   for j := index; j -> n-1
       a[index], a[j] = a[j], a[index]
       dfs(index+1)
       a[index], a[j] = a[j], a[index]
```

### 子集

这个题比较有意思，思想就是一个数字要还是不要

```
dfs(0->n)
	cur <- a[i]
	dfs(i+1)
	cur - a[i]
	dfs(i+1)
```

### 电话号码的组合

简单的模拟题，用哈希表记录数字对应的字符组合，然后遍历给出的数字串，从每个数字中取出对应的字符串，然后逐个组合到当前答案中，打最后一个数字时，放入到答案中。

### 组合总数

从不重复的数组选择数字组合成target，数字中的数字可以重复选

注意dfs时要去遍历数组，因为数组内的数字可以重复选，但为了避免答案中包含重复的组合，需要组合遍历数组的下标要大于等于前一个数字的下标，最后sum等于target放入数组

### 括号生成

n表示要生成的括号数量，递归时注意左括号不要大于n，同时右括号不能大于左括号数量，回退时有个巧妙的方法，就是用字符串的“+”操作作为参数，递归回来时，当前层的参数不变。

#### 单词搜索

标记好已经访问的位置，从所有位置开始遍历往四个方向搜索（完成后记得回溯），如果到达最后一个位置就返回true

### 分割回文串

先判断字符串中哪些片段是回文串（hash记录），然后遍历字符串，从下标开始到是回文串的位置后放入到当前cur中，然后判断下一个位置的字母，直到最后位置，存入答案，回溯时清理当前子串。

### N皇后 

判断i，j，i+j，i-j有没有皇后，判断当前行的皇后可行位置后组成字符串放入答案，直到最后n个皇后全部放完，回溯时清理之前组合。
